无界工作台 · 一键更新（旧版本专用）

适用：v0.21.0 / v0.21.1 / v0.21.2 等还没有应用内更新的版本。
作用：把程序更新到最新版本，保留你的作品、ComfyUI 模型、网关数据和设置。

使用方法（任选一种）：
1. 解压后双击「update.bat」，脚本会自动寻找桌面上的工作台文件夹。
2. 如果没找到，把整个工作台文件夹拖到「update.bat」图标上松手。
3. 也可以先打开「update.bat」，按提示粘贴工作台文件夹路径。

离线升级（v0.21.19 起）：
- 升级包目录里带 manifest.json 和补丁 zip 时，脚本直接使用本地补丁，全程不需要联网。
- 只有目录里没有本地补丁时，才会去魔搭下载最新补丁。

注意：
- 运行前建议关闭工作台窗口；不关也可以，脚本会尝试重启网关。
- 不需要重新下载模型；data、models、node_modules、launcher/config.json 不会被覆盖。
- 更新失败会自动回滚，原有程序不受影响。
- 以后版本会直接在应用内更新，不再需要这个工具。
